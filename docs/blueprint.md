# **App Name**: Som's Sakura Bloom

## Core Features:

- Hero Section Display: Showcase a primary romantic message with a breathing glow animation, fade-in effect, and a sub-headline.
- Reasons Why Gallery: Present a 3-card grid with glassmorphism effects, each containing a predefined message and an associated icon (Heart, Star, Sparkles).
- Interactive Love Catcher Game: A mini-game where a heart icon drops randomly within a confined box; upon 'catching', the heart grows/pulses, and 'Virtual Hug' and 'Power-Up' messages cycle.
- Playful Final Question: An interactive section with a romantic question, where the 'No' button cleverly evades the cursor, and the 'Yes' button triggers a confetti explosion and a loving final message.
- Themed Background & Accents: Integrate a 'Midnight Bloom Sakura' visual theme, including a falling sakura animation (with pointer-events: none), subtle glowing elements, and cute monkeys animated across the page.

## Style Guidelines:

- Primary accent color: A vibrant, romantic pink (#FF80BC) to highlight key messages and interactive elements, reflecting blossoming sakura against the night sky.
- Background color: A deep, desaturated purple-black (#261E25), creating a 'Midnight Bloom' atmosphere.
- Analogous accent color: A soft, glowing light pink/lavender (#F5BFED) for subtle details, hover states, and ethereal light.
- Additional accents: A metallic-like rose gold (#B76E79) for sophisticated touches and pure white (#FFFFFF) with glowing effects for high-contrast text and vital information.
- Headline font: 'Playfair' (serif) for an elegant, high-end, and fashionable romantic feel.
- Body text font: 'PT Sans' (sans-serif) for modern readability and warmth, complementing the elegant headlines.
- Use stylized Heart, Star, and Sparkles icons for the 'Reasons Why' gallery cards, and incorporate cherry blossom 🌸, sparkle ✨, and heart ❤️ emojis for the confetti effect on 'Yes' click.
- Clean, single-page, responsive design focusing on centered content for the hero, a 3-card grid for the gallery, and a clearly defined confined box for the interactive game, utilizing generous whitespace to enhance focus on key romantic messages.
- Atmospheric 'Falling Sakura' animation (with pointer-events: none), breathing glow and smooth fade-in for the hero section, heart grow/pulse on capture in the Love Catcher game, playful 'No' button evasion, and a massive confetti explosion on 'Yes' click.
